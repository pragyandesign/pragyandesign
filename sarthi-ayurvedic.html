The mark

Built on a grid, not a hunch

The mark reads as a raindrop from a distance and a compass needle up close, so it works as a tiny app icon and as a two-metre trade-show badge.

  • Grid 8 columns, 3° corner rule carried through every icon
  • Weight stroke matches the display type's stem width
  • Minimum size 20px, tested on-screen at that size
